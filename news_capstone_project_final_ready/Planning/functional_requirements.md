# Functional Requirements

1. Readers must be able to register, log in, and view approved articles.
2. Journalists must be able to create, edit, and delete their own articles.
3. Editors must be able to approve submitted articles.
4. Editors must be able to create publishers and manage content oversight.
5. Journalists and editors must be able to create and edit newsletters.
6. Readers must be able to access subscribed content through the API.
7. The system must send notifications when an article is approved.
8. The system must log approved articles to an internal API endpoint.
9. The API must support role-based access control.
10. Authentication endpoints must issue JWT tokens for API usage.
