# UI Plan

## Layout Goals
- A clean landing page showing approved articles and newsletters.
- A role-aware dashboard for authenticated users.
- Clearly styled forms for article, newsletter, and publisher management.
- Easy-to-read cards, status badges, and action buttons.

## User Experience Goals
- Readers should quickly identify approved content.
- Journalists should have a direct path to content creation.
- Editors should immediately see management actions such as approval and publisher creation.
- Forms should provide consistent spacing, labels, and call-to-action buttons.
