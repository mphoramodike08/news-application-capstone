# Non-Functional Requirements

1. The codebase must follow PEP 8 conventions and remain readable.
2. The interface must be clear, structured, and easy to navigate.
3. The application must enforce role-based authorization.
4. The project must be modular, with responsibilities split across models, views, serializers, forms, permissions, and services.
5. The database design must support normalized relations between users, publishers, articles, and newsletters.
6. The project must include automated tests for API behaviour and permissions.
7. MariaDB must be supported as the primary assessment database, with environment-based configuration.
